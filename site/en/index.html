Setting it up

Installer

  1. Run VFilemanage-1.0.0-setup.exe.
  2. If a blue warning appears, click More info, then Run anyway. Please read the note below as well.
  3. Choose the install folder and shortcut options, then click Install.
  4. Launch VFilemanage from the Start menu.

Portable

  1. Download VFilemanage-1.0.0-win.zip.
  2. Right-click the ZIP, open Properties, tick Unblock near the bottom, and click OK. Skipping this can leave the app blocked.
  3. Unzip it wherever you like. A path without spaces or non-Latin characters is safest.
  4. Run VFilemanage.exe inside the folder.

If you see "Windows protected your PC"

This app isn't code-signed yet, so SmartScreen treats it as a program it hasn't seen before. It does not mean the file is damaged or malicious. Click More info › Run anyway to continue.

If you'd rather check first, verify the file's fingerprint (SHA-256) below before running it. If the value differs, the download was corrupted or the file isn't ours — don't run it, download it again.

Questions people ask

My antivirus flags it as dangerous

That's a common false positive for Electron apps without a code-signing certificate. Compare the SHA-256 value above; if it matches, add the file to your antivirus exclusions. If it doesn't match, the download was corrupted — get it again.

Does it move or copy my original files?

No. The app only remembers where each file is; the original stays exactly where it was. Creating, moving, or deleting folders inside the app does nothing to the files on disk.

You can also put the same file in several folders. It costs no extra disk space.

Where is my library stored?

In a single file, filetree.db, inside %APPDATA%\VFilemanage. Settings live next to it in config.json. Copy that folder and you can open the same library on another PC.

Can I switch from portable to the installer?

Just install it. Both versions look at the same folder, so there's nothing to migrate — everything you organised is still there.

What if I move or delete an original file?

It stays in the list, and the app tells you it can't find the original when you try to open it. You can remove it from the list or point it at the new location. If the whole drive is disconnected, it says so separately.

I can't install software on my work PC

Use the portable version. It runs from the folder you unzip it into and writes nothing to the registry. For what it's worth, the installer doesn't need administrator rights either — it installs for your account only.

How do I remove it completely?

Uninstall it from the Windows app list, or delete the folder if you used the portable version. To remove the library you built as well, also delete %APPDATA%\VFilemanage.
