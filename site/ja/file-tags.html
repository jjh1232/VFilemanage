Windows のファイルにタグを付ける — 付けられるファイルと付けられないファイル

Windows にもタグはありますが、すべてのファイルに付けられるわけではありません。

フォルダは、一つのファイルを一か所にしか置けません。「契約書」であり「2024 年」であり「取引先 A」でもあるファイルは、どのフォルダに入れても、ほかの切り口からは見つかりません。そこでタグを探すことになります。Mac の Finder には色のタグがありますが、Windows ではどうでしょう。

Windows でタグを付ける方法

  • ファイルを右クリックして 「プロパティ」 を開きます。
  • 「詳細」 タブの 「タグ」 欄に言葉を入れます。複数ならセミコロン（;）で区切ります。
  • エクスプローラーの検索欄にその言葉を入れると、タグの付いたファイルも一緒に見つかります。

タグはファイルの中の情報欄に書き込まれるので、別のフォルダに移してもついていきます。

タグ欄のないファイルが多い

問題は、この「タグ」欄が その形式にタグを保存する場所があるときだけ 表示されることです。jpg の写真や Word・Excel などの Office 文書にはありますが、png・pdf・txt をはじめ、多くの形式には「詳細」タブにタグ欄そのものがありません。

実際に使ってみると「写真は付けられるのにスクリーンショットは無理、文書はいけるのに pdf はだめ」という状態になります。まとめたいファイルの半分が抜けると、タグで探す習慣はなかなか根づきません。

形式に関係なくまとめる方法

タグがやろうとしていることは、結局 「一つのファイルを複数のまとまりに入れること」 です。ファイルの中に書き込まず外側で覚えておけば、形式を選びません。

VFilemanage はこの方式です。タグの代わりに 仮想フォルダ を使い、同じファイルを複数の仮想フォルダに同時に入れられます。

  • 「契約書」「2024」「取引先 A」の三つの仮想フォルダに同じ pdf を入れておけば、どこからでも見えます。
  • 元ファイルは一つで、元の場所から移動しません。ディスクを余分に使いません。
  • png・pdf・動画など形式を選びません。ファイルの中身を書き換えないからです。

そのかわり、このまとまりは VFilemanage の中でだけ 見えます。ファイルを別の PC に送っても、タグのようにはついていきません。ファイルと一緒に移す必要がある分類なら、Windows のタグ（対応している形式なら）かファイル名に書く方法が合っています。

ショートカット・ライブラリ・シンボリックリンクとの比較は ファイルを移動せずに整理する方法 にあります。
