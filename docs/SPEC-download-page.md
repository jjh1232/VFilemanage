# 배포 페이지 구현 스펙

Electron 파일 관리자의 다운로드 랜딩 페이지. 설치 버전(.exe)과 무설치 버전(.zip)을 함께 배포한다.

---

## 0. 먼저 채울 값

구현 전에 아래를 확정하고, 문서 전체의 플레이스홀더를 치환할 것.

| 플레이스홀더 | 설명 | 예시 |
|---|---|---|
| `{{APP}}` | 앱 이름 | Porter |
| `{{VER}}` | 버전 | 1.0.0 |
| `{{EXE_NAME}}` | 설치 파일명 | `{{APP}}-Setup-{{VER}}.exe` |
| `{{ZIP_NAME}}` | 압축 파일명 | `{{APP}}-{{VER}}-win-x64.zip` |
| `{{EXE_URL}}` / `{{ZIP_URL}}` | 다운로드 URL | GitHub Releases 링크 |
| `{{EXE_SIZE}}` / `{{ZIP_SIZE}}` | 파일 크기 | 84.2 MB |
| `{{REPO}}` | 저장소 URL | |
| `{{DATE}}` | 릴리스 날짜 | 2026-09-03 |
| `{{SHA_EXE}}` / `{{SHA_ZIP}}` | SHA-256 | `Get-FileHash .\파일 -Algorithm SHA256` |

값이 아직 없으면 플레이스홀더를 그대로 남기지 말고 `TODO:` 주석과 함께 눈에 띄는 더미를 넣을 것.

## 1. 목표와 범위

- **주 목표**: 방문자가 자기에게 맞는 빌드를 30초 안에 고르고 받게 한다.
- **부 목표**: 서명되지 않은 Electron 앱 특유의 경고(SmartScreen, 백신 오탐) 때문에 이탈하거나 문의를 남기지 않게 한다.
- **범위 밖**: 로그인, 결제, 다국어, 애널리틱스, 블로그.
- **언어**: 한국어 단일.

## 2. 기술 제약

- 정적 페이지. 빌드 툴 없이 `index.html` 하나로 완결. CSS·JS 인라인.
- 외부 폰트·CDN·라이브러리 금지. 시스템 폰트 스택과 인라인 SVG만 사용.
- GitHub Pages 서브경로에 올려도 깨지지 않도록 모든 링크는 상대 경로 또는 절대 URL.
- JS는 클립보드 복사 하나뿐. JS가 꺼져도 다운로드와 모든 문서 내용은 읽혀야 한다.
- 메타 태그: `title`, `description`, `og:title`, `og:description`, `og:image`(있으면), `theme-color`.

## 3. 디자인 방향

파일 관리자라는 주제를 레이아웃 자체에 쓴다. 다운로드 영역을 카드 두 장으로 나열하지 말고 **파일 목록(리스트 뷰)** 형태로 만든다. 히어로에는 앱 창을 CSS로 재현해 릴리스 폴더를 열어 둔 화면을 보여준다. 제품 소개와 다운로드 UI가 같은 것이 되는 구조.

### 3.1 컬러 토큰

```css
--paper:      #EEEEE8;  /* 페이지 배경, 차가운 오트 */
--panel:      #FFFFFF;  /* 카드·테이블·앱 창 표면 */
--ink:        #171A1D;  /* 본문 */
--ink-2:      #5E6572;  /* 보조 텍스트 */
--ink-3:      #8A9099;  /* 메타, 캡션 */
--rule:       #D9D9D1;  /* 구분선 */
--rule-2:     #E8E8E1;  /* 약한 구분선 */
--accent:     #3D2FA8;  /* 딥 바이올렛 — 링크, 주 버튼, 선택 행 */
--accent-soft:#EDEBFA;  /* 선택 상태 배경 */
--amber:      #D99B2B;  /* 폴더 아이콘 + 경고 노트에만 */
```

앰버는 폴더 글리프와 SmartScreen 안내 블록에만 쓴다. 그 외 강조는 전부 바이올렛.

### 3.2 타이포그래피

패밀리 하나로 굵기·자간만 조절한다.

```css
--font-ui: "Pretendard Variable", Pretendard, -apple-system, BlinkMacSystemFont,
           "Apple SD Gothic Neo", "Segoe UI", "Malgun Gothic", "Noto Sans KR", sans-serif;
--font-mono: ui-monospace, "SF Mono", "Cascadia Mono", Consolas,
             "D2Coding", "Nanum Gothic Coding", monospace;
```

| 역할 | 크기 | 굵기 | 자간 / 행간 |
|---|---|---|---|
| H1 | `clamp(2.1rem, 5.4vw, 3.4rem)` | 800 | `-0.022em` / 1.15 |
| H2 | 1.75rem | 700 | `-0.022em` / 1.15 |
| H3 | 1.0625rem | 700 | `-0.01em` |
| 본문 | 1rem | 400 | 1.65 |
| 보조 | 0.9375rem | 400 | 1.6 |
| 메타 | 0.8125rem | 400 | |
| 파일 목록 | 0.78125rem | mono | |

- 본문 최대 폭 `60~70ch`. 그 이상 늘어나지 않게.
- 모노스페이스는 **파일명, 경로, 크기, 해시, 명령어**에만. 라벨 장식용으로 쓰지 말 것.
- 숫자 열은 `font-variant-numeric: tabular-nums`.
- 전부 문장형 대소문자. 라벨을 대문자로 늘여 쓰지 않는다.

### 3.3 레이아웃

- 컨테이너 `width: min(1060px, 100% - 44px)`, 가운데 정렬. 내용은 좌측 정렬.
- 섹션 세로 리듬은 `.band { padding: 84px 0 }` 단일 클래스로. 배경 변형은 `.band--panel` 같은 모디파이어만 추가하고 패딩을 다시 선언하지 말 것 (셀렉터 상쇄 주의).
- 라운드: 버튼 8px, 표면 10~12px, 배지 999px. 전부 같은 값으로 통일하지 않는다.
- 그림자는 히어로 앱 창 **하나만**. `0 18px 44px -26px rgba(23,26,29,.32)`.

### 3.4 하지 말 것

- 동일한 라운드 카드 격자에 내용을 다지는 구성
- 모든 카드에 같은 회색 그림자, 그라데이션 장식
- 제목 위 대문자 아이브로우 라벨
- 버튼·링크 텍스트 뒤 `→`
- 순서가 아닌 항목에 `01 / 02 / 03` 번호 매기기 (설치 절차는 실제 순서이므로 번호 OK)

## 4. 페이지 구조

```
┌ 상단 바 (sticky, 56px)
│  {{APP}}  ·  다운로드 / 버전 비교 / 설치 방법 / FAQ  ·  v{{VER}} 배지
├ 히어로 — H1 + 리드 + 버튼 2개 + 앱 창 재현
├ 다운로드 — 파일 목록형 행 2개
├ 버전 비교 — 표 (panel 배경)
├ 설치 방법 — 2열 절차 + SmartScreen 노트 + 체크섬 확인
├ 시스템 요구 사항 — 4칸 그리드 (panel 배경)
├ 자주 묻는 질문 — details/summary 아코디언
├ 변경 사항 — 좌측 버전/날짜, 우측 목록 (panel 배경)
└ 푸터
```

### 4.1 히어로

- H1: `한 창에서 끝내는 파일 관리` — 실제 기능에 맞춰 조정. 최대 15자 내외 2줄.
- 리드: `탭, 듀얼 패널, 즉시 검색을 갖춘 Windows 파일 관리자입니다. 설치해서 쓰거나, 압축만 풀어서 바로 실행하세요.`
- 버튼: 주 버튼 `설치 버전 받기 · {{EXE_SIZE}}` (채움), 보조 `무설치 ZIP 받기 · {{ZIP_SIZE}}` (외곽선). 옆에 `Windows 10 · 11 (64비트)` 캡션.
- **앱 창 재현** — 이 페이지의 핵심 요소. 다음을 CSS/HTML로만 만든다.
  - 크롬 바: 신호등 점 3개, 탭 3개(`releases` 활성 / `Downloads` / `+`)
  - 경로 바(mono): `C:\ › Users › you › {{APP}} › releases\{{VER}}`, 마지막 조각만 진하게
  - 좌측 사이드바: 바로 가기 / 바탕 화면 / 다운로드 / **releases**(선택) / 문서 / 로컬 디스크 (C:)
  - 파일 목록: 헤더 행 `이름 · 크기 · 수정한 날짜`, 그 아래 6행
    - `win-unpacked` (폴더, 앰버 글리프)
    - `{{EXE_NAME}}` — {{EXE_SIZE}} — **선택 상태**
    - `{{ZIP_NAME}}` — {{ZIP_SIZE}} — **선택 상태**
    - `checksums.txt`, `latest.yml`, `RELEASE_NOTES.md`
  - `role="img"` + 설명형 `aria-label` 부여. 스크린 리더가 행을 하나씩 읽지 않게 한다.

### 4.2 다운로드

카드가 아니라 위아래 구분선으로 나뉜 **행 2개**. 각 행은 `아이콘 / 본문 / 우측 버튼` 3열 그리드.

**행 1 — 설치 버전** (`권장` 배지)
> 설치하면 시작 메뉴와 바탕 화면에 등록되고, 새 버전이 나올 때 앱 안에서 바로 업데이트됩니다. 특별한 이유가 없다면 이쪽을 받으세요.

메타(mono): `{{EXE_NAME}}` · `{{EXE_SIZE}}` · `x64`

**행 2 — 무설치 버전**
> 압축을 푼 폴더에서 바로 실행됩니다. 관리자 권한이나 레지스트리 등록 없이 동작하므로 회사 PC나 USB에서 쓰기 좋습니다. 업데이트는 새 압축 파일을 직접 받아 덮어써야 합니다.

메타(mono): `{{ZIP_NAME}}` · `{{ZIP_SIZE}}` · `압축 해제 후 약 320 MB`

### 4.3 버전 비교

리드: `기능 차이는 없습니다. 아래 항목 중 마음에 걸리는 게 있는 쪽을 피하시면 됩니다.`

| 항목 | 설치 버전 (.exe) | 무설치 버전 (.zip) |
|---|---|---|
| 설치 과정 | 설치 마법사 실행 | 압축 해제만 하면 끝 |
| 관리자 권한 | 설치할 때 한 번 필요 | 필요 없음 |
| 자동 업데이트 | 앱에서 알림 후 자동 설치 | 직접 내려받아 교체 |
| 시작 메뉴 · 바로 가기 | 자동 등록 | 직접 만들어야 함 |
| 우클릭 메뉴 연동 | 지원 (설치 중 선택) | 지원하지 않음 |
| 설정 저장 위치 | `%APPDATA%\{{APP}}` | 실행 폴더 안 `data\` |
| USB 휴대 | 불가 | 가능, 설정까지 함께 이동 |
| 삭제 방법 | 설정 › 앱에서 제거 | 폴더 삭제 |
| 이런 분께 | 내 PC에서 오래 쓸 분 | 설치 권한이 없거나 흔적을 남기고 싶지 않은 분 |

> **확인 필요**: `자동 업데이트`는 electron-updater를, `우클릭 메뉴 연동`은 컨텍스트 메뉴 등록을 실제로 구현한 경우에만 남길 것. 아니면 두 행을 삭제한다.

각 행에서 유리한 쪽 셀만 `--ink`로, 나머지는 `--ink-2`로 두어 눈이 가게 한다. 체크/엑스 아이콘은 쓰지 않는다.

### 4.4 설치 방법

2열. 좌측 설치 버전, 우측 무설치 버전. 번호 원형 마커(`--ink` 배경, 종이색 숫자, mono).

**설치 버전**
1. `{{EXE_NAME}}`을 실행합니다.
2. 파란 경고 창이 뜨면 **추가 정보**를 누르고 **실행**을 선택합니다. 아래 안내를 함께 읽어 주세요.
3. 설치 폴더와 바로 가기 옵션을 고르고 **설치**를 누릅니다.
4. 설치가 끝나면 시작 메뉴에서 {{APP}}를 실행합니다.

**무설치 버전**
1. `{{ZIP_NAME}}`을 받습니다.
2. ZIP 파일을 우클릭해 **속성**을 열고, 아래쪽 **차단 해제**에 체크한 뒤 확인을 누릅니다. 이 단계를 건너뛰면 실행이 막힐 수 있습니다.
3. 원하는 폴더에 압축을 풉니다. 경로에 한글이나 공백이 없는 편이 안전합니다.
4. 폴더 안의 `{{APP}}.exe`를 실행합니다.

**경고 안내 블록** (앰버 좌측 보더 3px, `#FBF7EC` 배경, 우측만 라운드)

제목: `"Windows에서 PC를 보호했습니다" 창이 뜬다면`
> 코드 서명 인증서를 아직 적용하지 않아 SmartScreen이 처음 보는 프로그램으로 판단한 것입니다. 파일이 손상됐거나 악성이라는 뜻은 아닙니다. **추가 정보 › 실행**을 누르면 진행됩니다.
>
> 불안하다면 실행 전에 아래 방법으로 파일 지문(SHA-256)을 확인하세요. 값이 다르면 내려받다 손상됐거나 다른 파일이므로 실행하지 말고 다시 받으시면 됩니다.

**체크섬 확인**

어두운 배경(`--ink`) 코드 블록에 명령어 + 복사 버튼:

```
Get-FileHash .\{{EXE_NAME}} -Algorithm SHA256 | Format-List
```

아래에 파일명·해시 2행. 복사 버튼은 성공 시 `복사됨`, 실패 시 `복사 실패`로 1.8초간 바뀌었다 되돌아온다.

### 4.5 시스템 요구 사항

4칸 그리드(모바일 2칸). 각 칸은 작은 라벨 + 굵은 값.

| | |
|---|---|
| 운영체제 | Windows 10 (1809) 이상 |
| 아키텍처 | 64비트 (x64) |
| 메모리 | 4 GB 이상 |
| 디스크 여유 공간 | 350 MB |

각주: `32비트 Windows와 ARM64 기기는 아직 지원하지 않습니다. macOS · Linux 빌드는 준비 중입니다.` — 실제 계획에 맞게 수정.

### 4.6 자주 묻는 질문

`<details>` / `<summary>`. 마커는 CSS 셰브론으로 대체하고 열릴 때 회전.

1. **백신 프로그램이 위험하다고 표시합니다** — 서명 안 된 Electron 앱의 오탐. SHA-256 대조 후 일치하면 예외 등록, 불일치면 재다운로드.
2. **무설치 버전에서 설치 버전으로 옮길 수 있나요** — 설치 후 앱 종료, `data\` 내용을 `%APPDATA%\{{APP}}`로 복사.
3. **설정과 즐겨찾기는 어디에 저장되나요** — 위 두 경로. 백업하면 다른 PC에서 동일 환경.
4. **업데이트는 어떻게 하나요** — 설치 버전은 앱 내 알림, 무설치는 새 ZIP 해제 후 `data\`만 이동.
5. **회사 PC에 설치 권한이 없습니다** — 무설치 버전 안내. 레지스트리 미사용.
6. **완전히 삭제하려면** — 설치 버전은 제거 후 `%APPDATA%` 폴더 삭제, 무설치는 폴더 삭제로 끝.

### 4.7 변경 사항

좌측에 버전(큰 글씨) / 날짜 / `첫 정식 릴리스`, 우측에 기능 목록. **실제 구현한 기능으로 교체할 것.** 초안:

- 탭과 듀얼 패널로 폴더를 나란히 열고 파일을 옮길 수 있습니다.
- 경로 입력줄에서 폴더 이름 일부만 쳐도 바로 이동합니다.
- 현재 폴더 아래 전체를 대상으로 파일 이름을 즉시 검색합니다.
- 여러 파일 이름을 규칙에 따라 한 번에 바꿉니다.
- 자주 쓰는 폴더를 왼쪽 바로 가기에 고정합니다.
- 밝은 테마와 어두운 테마를 지원하며 시스템 설정을 따라갑니다.

## 5. 카피 규칙

- 기능이 아니라 **사용자가 겪는 일**로 쓴다. "레지스트리 미등록 포터블 아키텍처" ✗ → "관리자 권한 없이 폴더에서 바로 실행" ○
- 버튼은 눌렀을 때 벌어지는 일을 그대로 적는다. `다운로드`, `복사`. `제출`·`확인` 같은 무의미한 동사 금지.
- 경고 문구는 사과하지 않는다. 무슨 일이 일어났고 어떻게 넘어가는지만 말한다.
- 한 문장 한 가지. 느낌표와 수식어 자제.

## 6. 인터랙션과 모션

- **연출은 하나만**: 페이지 로드 시 히어로 파일 목록이 위에서부터 60ms 간격으로 차례로 나타나고(`opacity` + `translateY(5px)`, 0.3s), 마지막에 두 릴리스 행의 선택 배경이 들어온다. 디렉터리를 읽어 들이는 장면.
- 섹션 스크롤 등장 애니메이션, 카드 호버 리프트는 **넣지 않는다**.
- 나머지 전환은 사용자 조작에 대한 응답만: 버튼 색 변화(0.15s), FAQ 펼침, 복사 버튼 라벨 변경.
- `@media (prefers-reduced-motion: reduce)`에서 `animation`·`transition` 전부 무효화.

## 7. 품질 기준

- 반응형 브레이크포인트 860px 하나. 모바일에서: 2열 → 1열, 앱 창 사이드바 숨김, 파일 목록 날짜 열 숨김, 상단 내비 링크 숨김, 다운로드 행 세로 스택.
- 비교 표는 좁은 화면에서 가로 스크롤(`min-width: 600px` + `overflow-x: auto`).
- `:focus-visible` 아웃라인 전역 지정. 키보드만으로 모든 다운로드 링크 도달 가능.
- 본문 대비 4.5:1 이상. `--ink-3`는 메타 텍스트에만.
- 앱 창 재현물은 장식이므로 내부 텍스트가 스크린 리더에 낱개로 읽히지 않게 처리.
