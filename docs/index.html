설치 방법

설치 버전

  1. VFilemanage-1.0.0-setup.exe를 실행합니다.
  2. 파란 경고 창이 뜨면 추가 정보를 누르고 실행을 선택합니다. 아래 안내를 함께 읽어 주세요.
  3. 설치 폴더와 바로 가기 옵션을 고르고 설치를 누릅니다.
  4. 설치가 끝나면 시작 메뉴에서 VFilemanage를 실행합니다.

무설치 버전

  1. VFilemanage-1.0.0-win.zip을 받습니다.
  2. ZIP 파일을 우클릭해 속성을 열고, 아래쪽 차단 해제에 체크한 뒤 확인을 누릅니다. 이 단계를 건너뛰면 실행이 막힐 수 있습니다.
  3. 원하는 폴더에 압축을 풉니다. 경로에 한글이나 공백이 없는 편이 안전합니다.
  4. 폴더 안의 VFilemanage.exe를 실행합니다.

"Windows에서 PC를 보호했습니다" 창이 뜬다면

코드 서명 인증서를 아직 적용하지 않아 SmartScreen이 처음 보는 프로그램으로 판단한 것입니다. 파일이 손상됐거나 악성이라는 뜻은 아닙니다. 추가 정보 › 실행을 누르면 진행됩니다.

불안하다면 실행 전에 아래 방법으로 파일 지문(SHA-256)을 확인하세요. 값이 다르면 내려받다 손상됐거나 다른 파일이므로 실행하지 말고 다시 받으시면 됩니다.

내려받은 파일 확인하기

PowerShell을 열고 파일이 있는 폴더에서 아래 명령을 실행하면 지문이 나옵니다.

Get-FileHash .\VFilemanage-1.0.0-setup.exe -Algorithm SHA256 | Format-List

자주 묻는 질문

백신 프로그램이 위험하다고 표시합니다

코드 서명이 되어 있지 않은 Electron 앱에서 흔히 나오는 오탐입니다. 위쪽 안내대로 SHA-256 값을 대조해 보시고, 값이 같다면 백신의 예외 목록에 추가해 주세요. 값이 다르면 내려받는 중에 파일이 손상된 것이므로 다시 받으시면 됩니다.

원본 파일이 옮겨지거나 복사되나요?

아니요. 이 프로그램은 파일이 어디 있는지를 기억할 뿐이고, 원본은 있던 자리에 그대로 둡니다. 앱 안에서 폴더를 만들고 옮기고 지워도 실제 파일에는 아무 일도 일어나지 않습니다.

같은 파일을 여러 폴더에 넣어 둘 수도 있습니다. 디스크를 더 쓰지 않습니다.

정리한 내용은 어디에 저장되나요?

%APPDATA%\VFilemanage 폴더 안의 filetree.db 파일 하나에 들어 있습니다. 설정은 같은 폴더의 config.json입니다. 이 폴더를 복사해 두면 다른 PC에서도 같은 라이브러리를 열 수 있습니다.

무설치로 쓰다가 설치 버전으로 옮길 수 있나요?

그냥 설치하시면 됩니다. 두 버전이 같은 폴더를 보기 때문에 따로 옮길 것이 없고, 정리해 둔 라이브러리가 그대로 이어집니다.

원본 파일을 옮기거나 지우면 어떻게 되나요?

목록에는 남아 있지만 열 때 "원본을 찾을 수 없습니다"라고 알려 줍니다. 목록에서 지우거나, 옮긴 위치를 다시 연결할 수 있습니다. 드라이브 자체가 연결되어 있지 않은 경우에도 따로 알려 줍니다.

회사 PC에 설치 권한이 없습니다

무설치 버전을 쓰시면 됩니다. 압축을 푼 폴더에서 바로 실행되고 레지스트리에 아무것도 쓰지 않습니다. 참고로 설치 버전도 현재 사용자 계정에만 설치되므로 관리자 권한을 묻지 않습니다.

완전히 지우려면 어떻게 하나요?

설치 버전은 Windows 설정의 앱 목록에서 제거하고, 무설치 버전은 폴더를 지우면 됩니다. 정리해 둔 라이브러리까지 없애려면 %APPDATA%\VFilemanage 폴더를 함께 삭제하세요.

첫 정식 릴리스
  • 깊은 폴더에 있는 파일을 한곳에 모아 두고, 더블클릭하면 원본이 연결된 프로그램으로 바로 열립니다.
  • 원본을 옮기지 않고 가상 폴더로 정리합니다. 같은 파일을 여러 폴더에 넣어도 원본은 하나입니다.
  • 폴더를 통째로 끌어다 놓으면 안쪽 구조까지 그대로 들어옵니다.
  • 가져올 때 이미지 · 비디오 · 문서 · 오디오 등 원하는 형식만 받도록 거를 수 있습니다.
  • 이미지와 영상은 썸네일로 보여 주고, 폴더마다 대표 이미지를 지정할 수 있습니다.
  • 보기 크기를 다섯 단계로 바꾸고, 이름 · 날짜 · 유형 · 크기로 정렬합니다.
  • 정리한 구조를 실제 폴더로 내보냅니다.
  • 비밀번호로 앱을 잠글 수 있습니다. 힌트도 함께 저장됩니다.
  • 한국어 · 영어 · 일본어 · 스페인어를 지원하고, 밝은 테마와 어두운 테마가 있습니다.
